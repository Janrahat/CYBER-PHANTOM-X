# Cyber Phantom X design notes

The CLI uses a dark terminal aesthetic, skull motif, neon green/red/cyan accents, a hooded-phantom brand, and a secret-menu panel concept. Terminal font colors depend on terminal support. The supplied concept image is a visual mockup; a terminal CLI cannot display that exact full-resolution poster in all environments. For best appearance use a monospace font and a terminal with ANSI color support.

All functions are defensive. No live phone tracking or private owner lookup is implemented.
